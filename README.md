# 🌍 Dünya Kâşifi - Artırılmış Gerçeklik ile Ülke Tanıtımı

Merhaba! 👋 **Dünya Kâşifi** projemize hoş geldiniz. Bu uygulama, **Artırılmış Gerçeklik (AR)** teknolojisini kullanarak dünya üzerindeki ülkeleri keşfetmenizi sağlayan interaktif ve mobil bir bilgi platformudur. Uygulama, her ülke hakkında temel bilgileri yenilikçi bir şekilde sunarak hem eğitici hem de keyifli bir deneyim sunmayı amaçlamaktadır.

### 🎯 Özellikler
- ✨ **Artırılmış Gerçeklik (AR)** ile interaktif keşif deneyimi.
- 🌐 Ülkelerin listelenmesi ve her ülke için detaylı bilgi ekranı (başkent, para birimi, nüfus, bayrak vb.).
- 🔍 Hızlı ve pratik arama özelliğiyle istediğiniz ülkeyi anında bulma.
- 🇺🇳 **Rest Countries API** üzerinden güncel ve gerçek zamanlı veri çekme.
- 🎨 Sade, anlaşılır ve kullanıcı dostu modern arayüz.
- 📱 React Native ve Expo ile cross-platform (hem iOS hem Android) geliştirme.

### 🚀 Kurulum ve Çalıştırma
Bu bölüm, projeyi hiç bilmeyen birinin adım adım kolaylıkla nasıl çalıştıracağını açıklamaktadır.

#### Gereksinimler
Başlamadan önce bilgisayarınızda aşağıdaki araçların kurulu olduğundan emin olmalısınız:
* [Node.js](https://nodejs.org/) (LTS versiyonu önerilir)
* [Git](https://git-scm.com/)
* Fiziksel cihazda test için telefonunuzda **Expo Go** uygulaması (App Store / Google Play).

#### Kurulum Adımları
1.  **Projeyi Klonlayın:**
    Terminali açın ve projeyi bilgisayarınıza klonlayın.
    ```bash
    git clone [https://github.com/asametduran/dunyaKasifi.git](https://github.com/asametduran/dunyaKasifi.git)
    ```

2.  **Proje Dizinine Gidin:**
    ```bash
    cd dunyaKasifi
    ```

3.  **Gerekli Paketleri Yükleyin:**
    Projenin ihtiyaç duyduğu tüm kütüphaneleri yükleyin.
    ```bash
    npm install
    ```

#### Uygulamayı Çalıştırma
1.  **Geliştirme Sunucusunu Başlatın:**
    Aşağıdaki komutla Expo geliştirme sunucusunu başlatın.
    ```bash
    npx expo start
    ```

2.  **Keyfini Çıkarın!**
    * **📱 Fiziksel Cihazda (En İyi Yöntem):** Telefonunuzdaki **Expo Go** uygulamasını açın ve terminalde çıkan QR kodu okutun. (Bilgisayar ve telefonunuzun aynı Wi-Fi ağında olması gerekir).
    * **🖥️ Web Tarayıcıda:** Terminal ekranı aktifken `w` tuşuna basın.
    * **🤖 Android Emülatörde:** Terminal ekranı aktifken `a` tuşuna basın.
